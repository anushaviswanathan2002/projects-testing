# Counter React App

A simple, accessible counter built with React and Vite.

## Features

- Increment, decrement, and reset the count
- Accessible controls with ARIA labels and a live-updating count
- Clean, responsive dark UI

## Tech Stack

- React 18
- Vite 5

## Scripts

- `npm install` — install dependencies
- `npm run dev` — start the dev server
- `npm run build` — build for production
- `npm run preview` — preview the production build

## Project Structure

```
index.html
vite.config.js
src/
  main.jsx     # React entry point
  App.jsx      # Counter component
  App.css      # Counter styles
  index.css    # Global styles / theme
```
