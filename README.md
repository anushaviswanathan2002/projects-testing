# projects-testing

Repository of small projects built during development.

## Memory Match

A classic memory card game built with **React 18** and **Vite**.

### Features

- 8 pairs of emoji cards per game
- Flip animation with 3D CSS transforms
- Match detection with visual + delay-based feedback
- Move counter and best-score persistence (localStorage)
- Restart / "Play again" button
- Fully responsive (3-column layout on small screens, 4-column on larger)

### Run

```bash
npm install
npm run dev
```

Then open the URL shown by Vite (typically `http://localhost:5173`).
