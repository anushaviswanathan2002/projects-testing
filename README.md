# Memory Match

A classic memory card-matching game built with **React** and **Vite**.

## Features

- 4×4 grid of 8 emoji pairs (16 cards)
- Smooth 3D card-flip animations
- Move counter and live timer
- Win banner when all pairs are matched
- "New Game" button to reshuffle and reset stats
- Persistent win counter across rounds in the current session
- Fully keyboard accessible (cards are buttons, focus-visible outline, ARIA labels)
- Responsive layout for mobile and desktop

## Run locally

```bash
npm install
npm run dev      # development server
npm run build    # production build
npm run preview  # preview the production build
```
